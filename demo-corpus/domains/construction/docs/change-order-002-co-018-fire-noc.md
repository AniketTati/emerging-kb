# CHANGE ORDER CO-018 — FIRE NOC COMPLIANCE WORKS

**Parent Contract:** Acme-MAH-CON-2025-01-EPC
**Change Order No.:** CO-018
**Date:** 26 November 2025
**Type:** Statutory compliance (KSFES Fire NOC conditions)

---

## 1. Description of Change

Following KSFES inspection on 21 November 2025, the Fire NOC was conditional on 4 site improvements. This Change Order covers all required works.

### Scope Additions

| Item | Description | Cost (INR) |
|---|---|---|
| 1. Additional emergency exit | New door D6-7 + external staircase on East elevation (per Drawing DAE-WCD-ARCH-007 Rev D) | 4,20,000 |
| 2. Fire pump upgrade | Replace 2,000 LPM diesel pump with 2,400 LPM unit | 7,80,000 |
| 3. Smoke extract for loading dock | New 40,000 CMH smoke extract fan + ducting + controls | 5,80,000 |
| 4. Signage + evacuation plans | NBC-compliant signage at all stair + corridor locations; floor evacuation plans | 1,20,000 |
| **Sub-total** | | **18,80,000** |
| Add: GST @ 18% | | 3,38,400 |
| **Total** | | **22,18,400** |

---

## 2. Justification

These works are **mandatory** for issuance of the KSFES Fire NOC, which is in turn mandatory for **occupancy certificate** by BBMP.

Without these works, Acme would not be able to take possession of the datacentre + delay all subsequent IT installation. Acme cannot afford the delay.
