## ⚠ Structural Note (Architect)

**The MAIN INTERNAL LOAD-BEARING WALL** dividing the East Server Hall (1,840 sq.m) from the West Server Hall (1,200 sq.m) is shown on this drawing positioned at **Grid line C, which is 5.4m from the East face** of the building.

This positioning was chosen to maximise the larger (East) server hall capacity (480 racks vs 320 racks for the West hall). The wall is shown as a 300mm RCC wall, full height from floor to ceiling.

**Note for Structural Engineer (Sundar Structural Consultants):** Please confirm that this 300mm RCC wall at Grid line C is structurally adequate to support the proposed 280mm slab loading at the First Floor level (which carries additional UPS + battery equipment). If a thicker wall or relocation is needed, please advise immediately.
