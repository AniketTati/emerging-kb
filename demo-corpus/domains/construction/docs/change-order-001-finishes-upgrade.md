# CHANGE ORDER CO-005 — FINISHES SPECIFICATION UPGRADE

**Parent Contract:** Acme-MAH-CON-2025-01-EPC (8 March 2025)
**Change Order No.:** CO-005
**Date of Change:** 12 March 2025
**Type:** Specification upgrade (owner-requested)

---

## 1. Description of Change

Acme has requested an upgrade of the anti-static vinyl floor specification for the server halls from standard ESD-rated vinyl to **high-performance ESD-rated vinyl** suitable for Tier IV datacentre certification.

### Specification Comparison

| Attribute | Original (BoQ A5) | Upgrade |
|---|---|---|
| Vinyl type | Heterogeneous PVC | Homogeneous PVC + carbon black |
| Static resistance | < 10⁹ Ω | < 10⁵ Ω |
| Tile size | 600 × 600 mm | 600 × 600 mm (same) |
| Thickness | 2.5 mm | 3.0 mm |
| Wear layer | 0.55 mm | 0.65 mm |
| Recyclability | 60% | 95% |
| Manufacturer | Generic ESD | Tarkett / Polyflor (specified) |
| Cost per m² | INR 1,840 | INR 2,540 |

### Quantity Affected

- 3,040 sq.m of vinyl flooring (both server halls)
- 600 sq.m already procured at original spec — to be substituted/topped-up (vendor return value INR 4.84 lakh)
- 2,440 sq.m fresh procurement at upgraded spec

---

## 2. Cost Impact

| Item | Cost (INR) |

## 3. Schedule Impact

- Vendor lead-time for upgraded vinyl: 8 weeks (vs 4 weeks for original)
- Substituting now causes 4-week delay in finishes phase
- Mitigation: bring fit-out crew earlier on internal partition + paint scope; net schedule impact: 0 days
- Confirmed by PM (Mr. Rakesh Iyer) — no impact on Mechanical Completion (target 28 Feb 2026)
