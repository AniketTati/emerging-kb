# NON-CONFORMANCE REPORT (NCR) — CABLE ROUTING DEVIATION

**NCR No.:** NCR-014
**Site:** Acme Whitefield Datacentre Phase-2
**Date Raised:** 12 October 2025
**Raised by:** Mr. Anand Krishnamurthy, Site Engineer — Civil (Mahalaxmi)
**Responsibility:** Phoenix MEP Services Pvt Ltd

---

## 1. Description of Non-Conformance

During the routine site walk-down on 12 October 2025, a deviation was observed in the electrical cable routing at Grid C-7 in the Ground Floor East Server Hall.

**Drawing Reference:** PMEP-WCD-MEP-001 Rev B (12 February 2025)
**Drawing requirement:** Main electrical cable run shall pass through Grid C with 600mm clearance from the East face of the load-bearing wall (Grid line D)

**Actual installation (as built):** Cable run is offset by **3 metres** from the drawing position, encroaching into the server-hall floor area, reducing the usable rack-row width by approximately 0.4m.

**Photographs:** 4 photos attached showing the deviation

---

## 2. Impact Assessment

| Aspect | Assessment |
|---|---|
| Functionality | LOW — the cable is electrically functional |
| Server hall rack capacity | MEDIUM — reduces East server hall rack count by 4 (from 456 to 452) |
| Safety | NONE — proper clearance maintained |
| Code compliance | OK — within NEC + Indian Electrical Code clearances |
| Aesthetics | LOW |
| Future maintenance | LOW — accessible |

**Overall severity:** Medium (rack count impact on Acme's commercial capacity)

---

## 3. Root Cause Analysis (initial)

Per Phoenix MEP's initial response (Mr. Sushil Patil, 12 October 2025):

The cable routing crew encountered a structural beam at the drawing-specified position that was not visible in the MEP coordination model (a draft revision had been issued but the cable installation team was using the old drawing). The crew made a field decision to offset the run rather than escalate.

Contributing factors:
- Cable installation crew did not have the latest drawing version (Rev B was current; they had Rev A)
- Site supervision did not verify drawing version before commencement of cable pulling
- No formal RFI was raised; decision was made unilaterally by the crew

---

## 4. Corrective Action

### Option 1: Re-routing (preferred)

- Remove + re-pull the cable run to drawing-specified position
- Cost: ~INR 1.8 lakh (cable salvage + labour + small additional materials)
- Schedule impact: 4-5 working days

### Option 2: Accept-as-is + commercial adjustment

- Acme + Mahalaxmi to accept the deviation
- Reduce rack capacity in commercial reporting (East server hall 452 racks vs 456 spec)
- Commercial adjustment: Mahalaxmi to absorb a reduction in retention release or equivalent (~INR 5-8 lakh value)

---

## 5. Acme's Decision (15 October 2025)

After review by Mr. Sanjay Tripathi (Acme Procurement) + Mr. Vikram Iyer (Acme Project Owner):

**Decision:** Option 1 — Re-route to drawing.

**Rationale:**
- Acme has committed rack capacity to internal customers based on the 456-rack East server hall
- Re-routing is a relatively low-cost remedy
- Schedule impact (5 days) can be absorbed by parallel work in other zones

---

## 6. Action Plan

(i) Phoenix MEP to remove existing cable run (week of 20 October 2025)
(ii) Drawing version check + reissue confirmed; cable team retrained on drawing version management
(iii) Re-pull to drawing-specified position by 28 October 2025
(iv) Photo + drawing verification by site engineer before close-out
(v) Update as-built drawings accordingly

---

## 7. Lessons Learnt

- Drawing version control needs strengthening across MEP team
- Field-decision protocols should require RFI for any deviation from drawings
- Site supervision spot-checks should include drawing version verification

---

## 8. Closure Status

**Status as of 28 October 2025:** Re-routing completed. Verified by site engineer (Anand Krishnamurthy). NCR-014 CLOSED.
